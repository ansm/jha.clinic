# Jha's Physiotherapy & Acupuncture Centre website

Static 2-page website suitable for GitHub Pages.

## Files
- `index.html` - landing page
- `contact.html` - contact/location page
- `assets/styles.css` - styling
- `assets/logo.svg` - lightweight custom brand mark

## Publish free with GitHub Pages
1. Create a new public GitHub repository.
2. Upload all files and folders from this package to the repository root.
3. In GitHub: **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide a free `https://<username>.github.io/<repo>/` URL.
